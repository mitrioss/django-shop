# E-commerce Platform with Django

## Описание проекта

Этот проект представляет собой интернет-магазин, разработанный на Django. Он включает в себя функционал для управления продуктами, категориями, заказами, корзиной, оплатой и отзывами. Пользователи могут просматривать продукты, добавлять их в корзину, оформлять заказы и оставлять отзывы. Также реализована интеграция с платежной системой Stripe для обработки платежей.

## Основные функции

### Управление продуктами
- Просмотр списка продуктов с возможностью фильтрации по категориям.
- Просмотр детальной информации о продукте, включая отзывы.
- Добавление отзывов к продуктам (только для авторизованных пользователей).

### Корзина и заказы
- Добавление продуктов в корзину.
- Оформление заказов с указанием данных пользователя.
- Асинхронная обработка заказов с использованием Celery.

### Оплата
- Интеграция с платежной системой Stripe для обработки платежей.
- Успешное завершение оплаты или отмена платежа.

### Поиск
- Поиск заказов по имени пользователя.

### Дополнительные страницы
- Страница "О нас" (`about`).
- Страница "Правила" (`rules`).

## Технологии

- **Django**: Основной фреймворк для разработки приложения.
- **Stripe**: Платформа для обработки платежей.
- **Celery** (опционально): Для асинхронной обработки задач (например, отправка уведомлений о создании заказа).
- **Bootstrap** (опционально): Для стилизации интерфейса (не включено в текущую версию, но может быть добавлено).
